# واجهة الحجز — موقع صغير قابل للتثبيت

موقع حجز لعيادة أ.د. أسامة شعير، مبني على نفس عقود Easy!Appointments API،
ومصمم mobile-first عشان تتثبّت على الموبايل وتشتغل كتطبيق.

**٦ صفحات:** الرئيسية · الحجز · العيادة · عن الدكتور · الخصوصية · المطوّر — منيو واحد بيوصلك لأي واحدة.
كل خطوة في الحجز **بتقدر ترجع فيها** وتغيّر اختيارك بدون ما تبدأ من الأول.

## المميزات

| | |
| --- | --- |
| **قابل للتثبيت** | PWA كامل — يتثبّت على أندروید و iOS من المتصفح، ويفتح standalone بدون شريط عنوان |
| **يعمل جزئيًا أوفلاين** | service worker بيخزّن الواجهة، والمواعيد دايمًا من الشبكة |
| **٣ لغات** | مصري · خليجي · إنجليزي — تبديل فوري، والاتجاه RTL/LTR بيقلب معاها |
| **لايت / دارك** | بيتذكر اختيارك، وبيتبع النظام أول مرة، وبدون وميض عند التحميل |
| **موبايل أولًا** | breakpoints من 320px، أهداف لمس ≥ 40px، ومساحات آمنة للشاشات ذات النوتش |
| **خصوصية** | «إشعارات سرّية» بتشيل اسم العيادة والتخصص من التأكيد وملف التقويم |
| **امتثال** | موافقة صريحة بنسخة وتاريخ (قانون ١٥١/٢٠٢٠) |
| **تراجع في أي خطوة** | الـ stepper أزرار، وملخّص فوق الفورم فيه «تعديل» لكل اختيار، وزرار رجوع في كل خطوة |
| **بدون dependencies** | صفر مكتبات — Node 18+ فقط |

## الهيدر والمنيو

كل حاجة جوه **كبسولة واحدة** (`.nav-pill`): الأفاتار، روابط الصفحات، اختيار اللغة،
تبديل الثيم، وزر الإجراء الممتلئ.

- **الموبايل:** أفاتار + (لغة · ثيم · منيو) — والأفاتار لوحده من غير اسم،
  لأن الاسم في الهيرو على بعد تمريرة واحدة.
- **المنيو:** شيت من تحت فيه الأربع صفحات + تليفون وواتساب. الصفحة الحالية
  معلّمة بلون دهبي، و`Escape` أو لمسة برّه بتقفلها.
- **1040px+:** الروابط بتظهر في الكبسولة نفسها، وزر المنيو بيختفي.
- **560px+:** اسم الدكتور ولقبه بيظهروا.
- **≤359px:** زر الإجراء بيرجع أيقونة بس.

زر الإجراء بيتغيّر حسب الصفحة: «احجز موعدك» في كل الصفحات، و«اتصل» جوه صفحة الحجز.

## الرجوع عن الاختيارات

ده كان أهم طلب، واتعمل في تلات طبقات فوق بعض:

1. **الـ stepper أزرار** — أي خطوة اختيارها موجود تروحلها بلمسة.
2. **ملخّص فوق الفورم** — «الخدمة» و«الموعد» وكل واحد جنبه «تعديل»،
   وبيرجّعك للخطوة اللي بتخصه على طول.
3. **زرار رجوع في كل خطوة** + زرار الرجوع في المتصفح نفسه
   (`history.pushState` مع كل خطوة، و`popstate` بيرجّعك).

لو غيّرت الخدمة، التاريخ والوقت بيتفضّوا لوحدهم (مش منطقيين لزيارة تانية)
وفيه toast بيقولك إن ده حصل.

> ⚠️ `<picture>` عنصر **inline** بطبيعته، فـ `width` عليه بتتجاهَل والصورة
> تترسم بمقاسها الأصلي — ده اللي كان بيخلي اللوجو يكبر ويطلع بره الشريط.
> الإطار بقى `<span>` بـ `display: block`، والفحص الثابت بيمنع رجوع الباج.

## تطبيق الأندرويد

التطبيق **PWA قابل للتثبيت**: من Chrome على الأندرويد، زر «تثبيت» بينزّل أيقونة
بتفتح ملء الشاشة وتشتغل بدون نت. مفيش ملف `.apk` في الريبو — تفاصيل السبب
وطرق الحصول على APK/AAB (PWABuilder أو Bubblewrap) في **[ANDROID.md](ANDROID.md)**.

الحاجات اللي بتخلّي التثبيت يشتغل:

| الملف | الدور |
|---|---|
| `manifest.webmanifest` | الهوية، الأيقونات، الاختصارات، `display: standalone` |
| `sw.js` | تشغيل بدون نت + كاش النسخة (`v4`) |
| `install.js` | التقاط `beforeinstallprompt` + كشف WebView + التحويل لـ Chrome |
| `.well-known/assetlinks.json` | تصريح الموقع لتطبيق TWA (بصمة التوقيع) |
| `twa-manifest.json` | إعدادات بناء APK/AAB |

> **أهم سبب لفشل التثبيت:** فتح الرابط من جوّه واتساب/انستجرام. الـ WebView دي
> ما بتعرفش تثبّت PWA — والتطبيق بقى بيكتشف الحالة ويقول لك «افتح في Chrome»
> بزرار ينقلك على طول.

## الفحص

تلات طبقات — الأولى والتانية من غير أي اعتماديات، والتالتة محتاجة jsdom.

```bash
npm run audit                       # ٥٠ فحص ثابت: CSS · classes · ترجمة · صفحات
npm run check:install               # ١٠١ فحص جاهزية التثبيت على الأندرويد
npm run smoke                       # ٨٦ فحص على نشرة (محلي أو Vercel)
npm run smoke -- https://<project>.vercel.app

npm install && npm run check:ui     # ١٩١ فحص سلوك في DOM
```

| الأداة | بتكشف إيه |
| --- | --- |
| `audit.js` | قوس CSS مفتوح، class من غير تنسيق، مفتاح ترجمة ناقص في لغة، ملف مش موجود على القرص، صفحة مش بتحمّل `core.js`، لينك لصفحة مش موجودة، لهجة خليجية اترجعت للفصحى |
| `smoke.js` | الصفحة نفسها هي التطبيق مش صفحة خطأ، كل ملف ثابت ونوعه، الملفات الداخلية محجوبة، `/api/*` بيرد |
| `install-check.js` | المانيفست، أبعاد الأيقونات الحقيقية من الـ PNG، الـ Service Worker، ربط كل صفحة بالمانيفست، `assetlinks.json` |
| `ui-check.js` | ١٩١ فحص سلوك: المنيو والفوتر، الرئيسية، الصفحات الست، الخطوات الأربعة، **الرجوع وتغيير الاختيار**، الـ validation، الـ ٣ لغات، الثيم، وكل مسارات التثبيت |

> `jsdom` اعتمادية تطوير بس — الموقع المنشور فضل **صفر مكتبات**،
> و`package.json` نفسه مستثنى من الرفع في `.vercelignore`.

## الصور

`tools/make-photo.py` و`tools/make-avatar.py` بيضغطوا صورة الدكتور.

### صورة الطبيب

الصورة الأصلية ٨٨٠×٦٠٨ JPEG (صورة صحفية أفقية) — محتاجة قصّ، لأن إطار الهيرو
نسبة ٤:٥ والوجه لازم يفضل في الثلث العلوي. `tools/make-photo.py` بيقصّ الصورة
على إطار ٤:٥ وبيطلع نسختين (240 و480) بصيغتين:

```bash
python3 tools/make-photo.py [مسار-الصورة]
```

| | JPG | WebP |
| --- | --- | --- |
| 240 | 7.7 KB | 3.8 KB |
| 480 | 19 KB | 8.3 KB |

الصفحة بتستخدم `<picture>` بـ `srcset`، فالموبايل بينزّل **3.8 كيلو بس**.

### أفاتار الهيدر

```bash
python3 tools/make-avatar.py
```

بوكس ٤٠٠×٤٠٠ حوالين الوش من نسخة 480، بيطلع `avatar-96` و`avatar-192`
بصيغتين (1.5 كيلو و3.1 كيلو WebP). الهيدر بيعرضه دايرة بإطار ذهبي.

> **الأيقونة (favicon / PWA) فضلت الـ ECG mark** مش صورة الوجه — عند ١٦ بكسل
> الوش بيتحوّل لبقعة، والرمز بيفضل مقروء.

## استراتيجية الكاش

| النوع | السياسة | السبب |
| --- | --- | --- |
| التنقل (HTML) | Network-first + fallback | يلتقط أي تحديث جديد فورًا |
| أصول ثابتة (CSS/JS/أيقونات) | Cache-first + revalidate | تحميل فوري، وتحديث في الخلفية |
| `/api/*` | **Network-only** | قائمة مواعيد قديمة = حجزين في نفس الوقت |

## الربط بـ Easy!Appointments الحقيقي

في `core.js` غيّر سطر واحد:

```js
const API_BASE = 'https://clinic.osamashaeer.com/index.php';
```

| البروتوتايب | Easy!Appointments |
| --- | --- |
| `POST /api/availability` | `POST /booking/get_available_hours` |
| `POST /api/register` | `POST /booking/register` |
| `GET /api/clinic` | يُبنى من `services` + `providers` + `settings` |

الاستجابة عند الخطأ بترجّع **كود** (`code`) مش رسالة، والواجهة بتترجمه
(`invalid_phone` · `consent_required` · `consent_stale` · `slot_taken`).

## إضافة لغة جديدة

1. أضف القاموس في `i18n.js` بنفس المفاتيح.
2. أضف عنصرًا في `window.LOCALES` بـ `id` و`dir` و`intl`.
3. أضف ترجمة أسماء الخدمات في `lib/clinic-data.js`.

مفيش نص عربي مكتوب جوه HTML — كله من القاموس عبر `data-i18n`.

## ⚠️ قبل التشغيل الفعلي

1. **الأسعار** في `lib/clinic-data.js` (`SERVICES`) قيم محسوبة من الأسعار المنشورة
   بالدولار — العيادة هي اللي تحدّدها. مرجع الأرقام المنشورة في
   `clinic/research/دوسيه-أسامة-شعير.md`.
2. **مواعيد العمل** `workingHours` و`workingDays` مأخوذة من الموقع الرسمي
   (الأحد/الثلاثاء/الخميس، ١–٤ مساءً بتوقيت القاهرة) — تحتاج تأكيد من العيادة.
3. **سياسة الخصوصية** — `#privacyLink` لازم يوصل لصفحة حقيقية.
4. **التخزين** — `BOOKINGS` في الذاكرة وبتضيع مع كل cold start.
5. **موافقة PDPC** — يُراجع الترخيص مع محامٍ (قانون ١٥١/٢٠٢٠، م. ١٢).
6. **`discreet_notifications`** حقل إضافي لازم يُضاف لجدول `customers`.
