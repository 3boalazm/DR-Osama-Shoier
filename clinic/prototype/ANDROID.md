# تطبيق الأندرويد — الحالة، والطرق الثلاث للحصول عليه

> **الخلاصة في سطر:** التطبيق **قابل للتثبيت على الأندرويد الآن** من متصفح Chrome
> (أيقونة على الشاشة، ملء الشاشة، ويعمل بدون نت). اللي **مش موجود** هو ملف `.apk`
> جاهز للتحميل — وده لأنه محتاج أدوات بناء (JDK + Android SDK) مش موجودة في بيئة
> التطوير اللي اتبنى فيها المشروع. تحت ثلاث طرق للحصول عليه، أسرعها دقيقتين.

---

## ١. الرابط الرسمي

```
https://prototype-shaeer.vercel.app
```

لازم يكون **HTTPS** و**بدون حماية تسجيل دخول**. مشروع Vercel المرتبط بالحساب
(`prototype-shaeer`) حالة الحماية فيه `ssoProtection: null` — أي أن الرابط مفتوح
للعامة، وده شرط أساسي للتثبيت.

> ⚠️ لو فتحت التطبيق من **جوّه واتساب أو فيسبوك أو انستجرام**، الصفحة بتفتح في
> WebView — ودي **ما بتعرفش تثبّت** PWA أصلًا. التطبيق بقى بيكتشف الحالة دي
> ويقول لك «افتح في Chrome» مع زرار ينقلك على طول. ده أكتر سبب شائع لفشل التثبيت.

---

## ٢. الطريقة (أ) — تثبيت فوري من Chrome (ثانية واحدة، بدون متجر)

1. افتح `https://prototype-shaeer.vercel.app` في **Chrome على الأندرويد**.
2. هتلاقي زر **«ثبّت التطبيق»** في الهيدر، أو من قائمة Chrome (⋮) → **«تثبيت التطبيق»**.
3. أكّد → الأيقونة بتنزل على الشاشة الرئيسية.

بعد التثبيت:

| | |
|---|---|
| فتح بدون شريط عنوان | ✅ `display: standalone` |
| يعمل بدون إنترنت | ✅ Service Worker بيخزّن كل الصفحات |
| أيقونة مخصّصة + شاشة بداية | ✅ ١٩٢ و٥١٢ + maskable |
| اختصارات بالضغط المطوّل | ✅ «حجز جديد» و«العيادة» |
| تحديث تلقائي | ✅ النسخة الجديدة تنزل في الفتحة اللي بعدها |

**ليه ده «تطبيق» فعليًا؟** أندرويد بيتعامل معاه كـ WebAPK — بيدخل في شاشة
التطبيقات، بيظهر في «التطبيقات الأخيرة»، وبيشتغل في نافذة مستقلة. الفرق الوحيد
عن APK عادي إنه مش موقّع ومش متاح على Google Play.

---

## ٣. الطريقة (ب) — ملف APK/AAB جاهز في دقيقتين (PWABuilder)

1. افتح <https://www.pwabuilder.com>.
2. الصق الرابط: `https://prototype-shaeer.vercel.app` → **Start**.
3. اختار **Android** → **Generate Package**.
4. نزّل `.apk` (للتجربة والتحميل المباشر) أو `.aab` (للرفع على Google Play).

PWABuilder بيبني نفس مشروع TWA الموجود في `twa-manifest.json` — يعني الإعدادات
اللي في الريبو مطابقة لللي هيولّده، ومش هتحتاج تعدّل حاجة.

> **ملاحظة:** أول APK بيطلع موقّع بمفتاح PWABuilder. سيب لك نسخة من المفتاح —
> أي تحديث بعد كده لازم يتوقّع بنفس المفتاح، وإلا Play هيرفض التحديث.

## ٤. الطريقة (ج) — بناء محلي بـ Bubblewrap (تحكم كامل)

### المتطلبات

- **JDK 17** — <https://adoptium.net>
- **Android SDK** — عن طريق Android Studio، أو `sdkmanager` من command line tools
- Node 18+

```bash
npm i -g @bubblewrap/cli

# هيقرأ twa-manifest.json الموجود في الريبو
bubblewrap init --manifest https://prototype-shaeer.vercel.app/manifest.webmanifest

bubblewrap build
```

المخرجات:

```
app-release-signed.apk    ← توزيع مباشر (تحميل/واتساب)
app-release-bundle.aab    ← رفع على Google Play
```

### بعد البناء — خطوة إلزامية واحدة

TWA بيفتح الموقع في نافذة من غير شريط عنوان **بشرط** أن الموقع يصرّح للتطبيق.
خد بصمة مفتاحك:

```bash
keytool -list -v -keystore android.keystore -alias android | grep SHA256
```

وحطّها في `.well-known/assetlinks.json` مكان المصفوفة الفاضية:

```json
"sha256_cert_fingerprints": ["AA:BB:CC:…:FF"]
```

ثم ارفع الملف (commit + push) وتأكد إنه متاح على:

```
https://prototype-shaeer.vercel.app/.well-known/assetlinks.json
```

> لو البصمة مش مظبوطة، التطبيق هيفتح **بشريط عنوان** — مش هيكسر، بس هتبان كأنها
> صفحة ويب. الملف موجود جاهز في `clinic/prototype/.well-known/assetlinks.json`.

## ٥. ليه مفيش `.apk` مرفوع في الريبو؟

بناء APK محتاج ثلاث حاجات مش متوفرة في بيئة العمل دي:

1. **JDK** — مفيش `java` على الجهاز.
2. **Android SDK** (`aapt2` / `d8` / `apksigner`) — وبيتحمّل من `dl.google.com`
   اللي مش متاح من الساندبوكس.
3. **مفتاح توقيع** — لازم يتولّد عندك ويتحفظ عندك، ومينفعش يتولّد في مكان عام.

عشان كده الريبو بيشحن **كل حاجة قبل خطوة البناء** (الأيقونات، المانيفست،
`twa-manifest.json`، `assetlinks.json`) ويسيب خطوة `build` في جهازك.

## ٦. قائمة تحقّق سريعة

```bash
npm run install-check     # ٤٠+ فحص آلي لجاهزية التثبيت
```

الفحص بيتأكد من: المانيفست، أبعاد الأيقونات الفعلية، الـ Service Worker،
ربط كل صفحة بالمانيفست، وملف assetlinks. لو كل حاجة خضراء، Chrome هيعرض
زر التثبيت — طالما الرابط HTTPS ومش جوه WebView.

## ٧. الأخطاء الشائعة

| العَرَض | السبب | الحل |
|---|---|---|
| مفيش زر تثبيت خالص | الصفحة مفتوحة من واتساب/انستجرام | افتحها في Chrome (التطبيق بيقول لك ده بنفسه) |
| الزر ظاهر وبيرجع «غير متاح» | Service Worker لسه ما سجّلش | اعمل refresh مرة واحدة، ثم جرّب |
| التطبيق فتح بشريط عنوان | `assetlinks.json` فاضي أو بصمة غلط | املأ البصمة وأعد النشر |
| أيقونة بيضاء/مشوّشة | أندرويد استخدم شكل مختلف | الأيقونة الـ maskable موجودة — تأكد إنها هي المستخدمة |
| «تم التثبيت» بس مفيش أيقونة | الأيقونة في درج التطبيقات مش الشاشة الرئيسية | اسحبها من الدرج |
