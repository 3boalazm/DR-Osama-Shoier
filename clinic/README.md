# نظام حجز مرضى مستشفى كمال شعير

طبقة تخصيص فوق **Easy!Appointments** (المندمج في جذر هذا الريبو) لتشغيل حجز مرضى أونلاين
لـ **مستشفى كمال شعير** — مركز الخصوبة وأمراض الذكورة — بإشراف **أ.د. أسامة كمال شعير**،
أستاذ طب وجراحة الذكورة بكلية الطب (القصر العيني)، جامعة القاهرة.

## تشغيل البروتوتايب

```bash
node clinic/prototype/server.js
# http://localhost:4173
```

أو على الإنترنت: **https://prototype-shaeer.vercel.app**

## ملخص التوصية

- **العمود الفقري:** Easy!Appointments مستضاف ذاتيًا (سيرفر داخل مصر)
- **الواجهة:** عربية RTL مخصصة — بتكلّم REST API مباشرة
- **التذكيرات:** واتساب Cloud API
- **الخصوصية:** وضع «إشعارات سرّية» + سجل موافقات متوافق مع قانون ١٥١/٢٠٢٠
- **بدائل مرفوضة:** Vezeeta كقناة **اكتساب** (ماركت بليس بيتحكم في اسم الطبيب وشكل ظهوره وسعره)، وSaaS جاهز (اشتراك شهري + بيانات خارج سيطرتك)
